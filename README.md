# 📖 About

This project is my personal cloud portfolio website built and deployed on **AWS EC2**.

It showcases my projects, technical skills, resume, and includes a fully functional contact form with secure backend authentication.

The complete application is hosted on Ubuntu using Nginx as a reverse proxy, PM2 for process management, Express.js backend, and MySQL database.

---

# 🚀 Features

- Responsive Portfolio Website
- AWS EC2 Deployment

- Nginx Reverse Proxy

# ⚙️ Installation

Clone repository

```bash
git clone https://github.com/aniketthakur9/MyPortfolioWebsite.git
```

Go into project

```bash
cd MyPortfolioWebsite
```

Install backend

```bash
npm install
```

Start server

```bash
npm start
```
